# Guidelines

## Code Style

### Conditional Statements
Always use curly braces for defining if blocks, even when the block contains only a single statement.

Example:
```javascript
// Good
if (condition) {
  doSomething();
}

// Avoid
if (condition)
  doSomething();
```

### Comments
Only add comments when explicitly requested. Do not add explanatory comments to code unless specifically asked to do so.
